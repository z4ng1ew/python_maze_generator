# 🏛️ PROTOCOL: LABYRINTH [Python]

**Цель:** Разработка вычислительного движка для генерации, визуализации и анализа лабиринтов и пещерных систем, включая внедрение агента на базе машинного обучения.

## ⚙️ Базовые ограничения и стандарты
* **Язык:** Python.
* **Стиль:** Google Python Style Guide.
* **Сборка:** `Makefile` (обязательные цели: `all`, `install`, `uninstall`, `clean`, `dvi`, `dist`, `tests`).
* **Тестирование:** Логика генерации, решения и RL-агента должна быть покрыта **Unit-тестами на 100%**.
* **GUI:** Десктопное приложение (любая библиотека: Tkinter, PyQt, CustomTkinter и т.д.).

## 🧩 Архитектура модулей

### Модуль 1. Холст (База и GUI)
* Загрузка лабиринта из текстового файла (матрицы стен).
* Отрисовка в окне **500x500 px**.
* Толщина стен — **2 px**.
* Размеры ячеек рассчитываются динамически, чтобы лабиринт (макс. 50x50) занимал всё окно.

### Модуль 2. Архитектор (Идеальный лабиринт)
* Генерация по **алгоритму Эйлера (Eller's algorithm)**.
* **Условие:** Лабиринт должен быть идеальным (нет изолированных зон, нет циклов).
* Пользователь задает только размерность (N x M).
* Результат сохраняется в файл и сразу отрисовывается.

### Модуль 3. Навигатор (Поиск пути)
* Поиск кратчайшего пути от точки А до точки Б.
* Отрисовка маршрута линией **2 px** (цвет должен контрастировать со стенами и фоном).
* Линия проходит строго через центры ячеек.

### Модуль 4. Биосфера (Пещеры / Клеточный автомат)
* Генерация пещер по правилам, аналогичным «Жизни» Конвея.
* Отдельная вкладка/окно в GUI.
* Настройки пользователя: пределы «рождения» и «смерти» (0-7), вероятность начального заполнения.
* **Режимы симуляции:**
  * *Пошаговый* (кнопка «Следующий шаг»).
  * *Автоматический* (с настраиваемой задержкой в мс).
* Границы поля всегда считаются «живыми» (стенами).

### Модуль 5. Разум (Q-Learning без внешних ML-библиотек)
* Обучение агента поиску кратчайшего пути до фиксированной цели в фиксированном лабиринте.
* **Важно:** Использование готовых RL-библиотек (типа Stable Baselines, Ray RLlib) **запрещено**. Алгоритм Q-обучения пишется с нуля.
* После обучения пользователь может выбрать любую стартовую точку, и агент визуально проложит оптимальный маршрут.

### Модуль 6. Сеть (Веб-интерфейс)
* Реализация веб-версии (SPA или MPA) на любом современном стеке.
* Должна полностью дублировать функционал **Модулей 1, 2 и 3**.

## 📄 Форматы данных (Справочно)

**Лабиринт:**
Первая строка: `rows cols`
Далее: матрица вертикальных стен (справа от ячейки), затем матрица горизонтальных стен (снизу от ячейки). `1` — стена, `0` — проход.

**Пещера (начальное состояние):**
Первая строка: `rows cols`
Далее: матрица состояния ячеек. `1` — живая (стена), `0` — мертвая (проход).
